# 미션 개요: 화성 기지 날씨 데이터베이스 구축

## 1. 배경 스토리
최단 경로가 정해졌으나 화성의 이산화탄소 대기로 인한 거대한 모래 폭풍이 한송희 박사의 발을 묶을 위험이 있습니다. 다행히 미션 컴퓨터 내에 모래 폭풍 주기가 백업되어 있으며, 한송희 박사는 이동하려는 날짜와 모래 폭풍 날짜가 겹치는지 분석하기 위해 날씨 데이터를 데이터베이스에 적재하려고 합니다.

## 2. 최종 목표
제공된 화성 날씨 CSV 데이터를 MySQL 데이터베이스에 안전하게 마이그레이션하고, 분석할 수 있는 파이썬 프로그램을 제작합니다.

## 3. 최종 산출물
- 작성된 모든 Python 코드는 `mars_weather_summary.env` 파일로 저장되어야 합니다.


# 기능 요구사항 및 데이터 명세

## 1. 데이터베이스 테이블 생성
MySQL에 데이터를 담을 테이블을 아래 명세에 맞게 생성해야 합니다.
- **테이블 이름**: `mars_weather`
- **컬럼 정보**:
  - `weather_id`: int / Primary Key / 자동 증가(Auto Increment) 설정
  - `mars_date`: datetime / 필수 입력(Not Null) 설정
  - `temp`: int
  - `storm`: int

## 2. 파이썬 프로그램 핵심 기능
1. **DB 연결**: Python 코드를 통해 생성한 MySQL 데이터베이스와 안전하게 연결합니다.
2. **CSV 파일 읽기**: 제공되는 `mars_weathers_data.csv` 파일을 읽어서 내용을 확인하는 로직을 작성합니다.
3. **데이터 적재**: CSV 파일의 내용을 읽어 `mars_weather` 테이블에 입력합니다. 
   - **중요**: CSV의 모든 행 데이터를 `INSERT` 쿼리로 변환하여 반복적으로 실행하도록 구성해야 합니다.

## 3. 보너스 과제 (선택 구현)
- `MySQLHelper` 클래스를 설계하여 데이터베이스 연결, 연결 해제 및 쿼리 실행 등을 객체 지향적으로 쉽게 관리할 수 있도록 모듈화합니다.


# 개발 제약 조건 및 코딩 스타일 가이드

## 1. 개발 환경 규칙
- **Python 버전**: Python 3.x 버전을 기준으로 작성합니다.
- **라이브러리 제한**: Python에서 기본 제공되는 표준 라이브러리 및 명령어만 사용해야 하며, 외부 서드파티 라이브러리나 패키지를 설치해서 사용해서는 안 됩니다. (단, MySQL 연결 및 CSV 처리에 필요한 내장 라이브러리는 허용)

## 2. 파이썬 코딩 스타일 가이드 (PEP 8 준수)
- **따옴표 규칙**: 문자열을 표현할 때에는 홑따옴표(`' '`)를 기본으로 사용합니다. 단, 문자열 내부에 홑따옴표가 포함되는 등 부득이한 경우에만 겹따옴표(`" "`)를 사용합니다.
- **공백 규칙**: 대입 연산자(`=`)의 앞뒤로는 반드시 공백을 한 칸씩 둡니다. (예: `foo = (0,)`)
- **들여쓰기**: 공백(Space) 4칸을 기본으로 사용합니다.
- **네이밍 규칙**: 
  - 함수명 및 변수명: 소문자로 작성하되, 두 단어 이상이면 언더바(`_`)로 구분하는 `snake_case`를 사용합니다.
  - 클래스명: 대문자로 시작하고 단어 조합 시 대문자로 이어나가는 `CapWords`(`PascalCase`) 방식을 사용합니다.
- **코드 안정성**: 경고 메시지(Warning)나 예외 발생으로 프로그램이 중단되지 않도록 파일 처리 및 DB 연결부에는 철저하게 예외 처리(`try-except`)가 적용되어야 합니다.
